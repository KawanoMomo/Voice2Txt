# ADR-draft: 初期プロンプトを言い淀みで終える — 文頭の稀な語をプロンプトの末尾から切り離す

- **ステータス**: 提案(未採番)
- **カテゴリ**: architecture
- **日付**: 2026-11-03
- **対象プロジェクト**: Voice2Txt
- **関連**: decoding-initial-prompt-no-final-period.md(末尾の句点を外した決定。並びを改める)、decoding-initial-prompt-counting-kana.md、decoding-initial-prompt-fillers.md、BLK-transcriber-20261103-2147

## コンテキスト

不動産の説明文の文頭「まどりは…」(かなの読み)が、既定の large-v3-turbo で「窓りは…」になった。初期プロンプトを外すと「間取りは…」で届く。
言い淀みの列だけ(`…えっと。`)・数える列だけ(`ここのつ、10`)でも「間取り」になり、両方を並べて数字「10」で終えた今のプロンプトでだけ「窓り」になる。
前の決定(句点で終えると「いちごいちえの」が「一期一への」)と同じく、プロンプトの末尾は発話の最初の語の直前の文脈として読まれ、文頭の語の当て方を変える。
文頭の語ごとに末尾の形を合わせる直し方では、次の稀な語で同じことが起きる。

## 検討した選択肢(large-v3-turbo、CUDA。utt-12・utt-15・utt-25・utt-31・yoji-01-r2・fudo-01-r2・fudo-02-r2)

| 初期プロンプト | まどりは | いちごいちえの | ひとつ…とお |
|---|---|---|---|
| (今)`えーと、…、えっと。ここのつ、10` | 窓り | 一期一会 | …10。 |
| 無し | 間取り | 一期一会 | …等 |
| 末尾に改行 | 間取り | 一期一への | …10。 |
| 末尾に空白 | 間取り | 一期一への | …10(句点が消える) |
| 全部読点でつなぐ | 窓り | — | — |
| **数える列を先頭・言い淀みで終える(`ここのつ、10。えーと、…、えっと`)** | **間取り** | **一期一会** | **…10。** |

## 決定

`Decoding.InitialPrompt` = `ここのつ、10。えーと、あの、ええと、その、まあ、えっと`。数える列は句点で閉じて先頭に置き、末尾を言い淀みにする。
話し言葉では言い淀みの次にどの語でも来るので、末尾が最初の語の選び方を偏らせない。句点でも数字でも終えない(unit で守る)。中身・長さ・文字種は変えない。
置換表・後処理・辞書・設定は増やさない。

## 結果

- corpus の 20 秒以下 277 本の新旧比較: 同じ 252、違う 25。正解文に近づいた 17(fudo-02・fudo-02-r2 の「間取り」、jyoubun-01 の「甲」「乙」、
  count-01・paren-01 の漢数字、katsu-01 の読点、keigo-01、eki-01、sym-01、josu-01、giongo-01・02 ほか)。
  離れた 8 は句読点・表記の揺れ(alt-01 の「？」、filler-01 の末尾「、」、hougen-01 の「なぁ」、inhale-02 の「売り上げ」、sushiki-01 の句点、unit-01 の単位が「cm」「kg」「L」)と、
  記録済みの NG の別の誤り(homo-01-r2 の同音異義・wontfix、shinzoku-01-r2)
- 「敷金」→「資金」(fudo-01-r2。文の途中)はプロンプトに関係しない: 無しでも large-v3 でも「資金」で、Haas だけが「敷金」。プロンプトでは直らない
- 台本 `transcriber-3` の utt-36(文頭「まどりは」)は「間取り」を含み「窓」を含まないことを守る。utt-31 の「一期一会」、utt-25 の「10」、utt-12 の言い淀みも同じ台本で守る
