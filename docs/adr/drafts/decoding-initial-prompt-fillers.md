# ADR-draft: 言い淀みが別の語に化ける — 復号の初期プロンプトで直す

- **ステータス**: 提案(未採番)
- **カテゴリ**: architecture
- **日付**: 2026-10-07
- **対象プロジェクト**: Voice2Txt
- **関連**: 仕様 5 章 8・7 章(句読点・表記の後処理、ユーザー辞書は後続)、BLK-transcriber-20261007-1023

## コンテキスト

「ええと」を含む発話で、確定版の「ええと」が英字の「A」+「と」(「Aと」)に化けて貼り付けられた。合成音声の音素(PhonemeReached)は
「エエト」で、音声は正解文どおり。同じ化け方は「ええと」を 2 回含む別の文でも起き、「えーと」「えっと」「あの」は化けない。
これまで復号は言語 `ja` を指定するだけで、プロンプトは無かった。

## 検討した選択肢

1. 「Aと」→「ええと」の置換表・後処理 — 化け方 1 つにしか効かず、届いた文字列を書き換える(後処理と辞書は仕様 7 章の後続)
2. 「以下は日本語の話し言葉です。」のような説明文のプロンプト — 試したが「Aと」は直らない
3. 言い淀みをかなで並べた短い初期プロンプト(`えーと、あの、ええと、その、まあ、えっと。`)— 話し言葉の書き方を先に見せる
4. beam search / best_of / no_context — 以前の検証でコーパスの結果が 1 文字も変わらない

## 決定

3 を採る。値は `Voice2Txt.Core.Decoding.InitialPrompt` に置き、`WhisperTranscriber` が `WithPrompt` で渡す。どのモデルでも同じ。
プロンプトはかなと句読点だけで短く保つ(unit で守る)。内容のある語を入れると、無音・短い発話でその語が出てくる種になる。

## 結果

- corpus 30 本 + 言い淀みの本 8 本 + tests/fixtures の 12 本で、悪くなった本は無い。「ええと」の化けは 3 本とも直った。
  無音の幻聴(「ご視聴ありがとうございました」)は変わらない(取り消し(無音)が先に止める)。文字起こしの時間は短文 0.24 秒前後で変わらない
- 言い淀みは消さずにかなで残る(消すかどうかは後処理の判断で、後続)
- 検証モードの台本 `transcriber-3`(`utt-12.wav`)で、化けが戻ったら赤になる
