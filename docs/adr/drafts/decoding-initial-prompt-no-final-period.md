# ADR-draft: 初期プロンプトを句点で終えない — 文頭の四字熟語の切れ目を変えない

- **ステータス**: 提案(未採番)
- **カテゴリ**: architecture
- **日付**: 2026-11-03
- **対象プロジェクト**: Voice2Txt
- **関連**: decoding-initial-prompt-counting-kana.md(「ここのつ、10。」にした決定。その末尾の句点を外す)、BLK-transcriber-20261102-1815(差し戻し 1 回目)

## コンテキスト

「ここのつ、10。」にした後、「いちごいちえの精神で…」の確定版は「151への」から「一期一への精神で…」になった。数字化は消えたが「会」が「への」になり、正解文と一致しない。
前の ADR は「初期プロンプトを外しても『への』になる(合成の声)」としていたが、今の main で外すと「一期一会の」で届く。

## 検討した選択肢(large-v3-turbo、CUDA。yoji-01-r2・utt-31・utt-25)

| 初期プロンプト | いちごいちえの | ひとつ…とお |
|---|---|---|
| (今)`えーと、…、えっと。ここのつ、10。` | 一期一への | …9つ、10。 |
| 無し | 一期一会の | …9つ、等 |
| `。` だけ | 一期一への | …9つ、等。 |
| 言い淀みの列だけ(`…えっと。`) | 一期一への | …9つ、等。 |
| 数える列だけ(`ここのつ、10。`) | 一期一への | …10。 |
| 数える列を先頭(`ここのつ、10。えーと、…えっと。`) | 一期一への | …10。 |
| 末尾に `よろしくお願いいたします。` | 一期一への | …10。 |
| 全部読点でつなぎ句点無し | 一期一会の | …10(句点が消える) |
| 末尾を読点(`…ここのつ、10、`) | 一期一会の | …10、(読点で終わる) |
| **末尾の句点だけ外す(`…えっと。ここのつ、10`)** | **一期一会の** | **…9つ、10。** |

句点で終わるプロンプトなら中身に関係なく「への」になり、句点で終えなければ「一期一会」になる。

## 決定

`Decoding.InitialPrompt` = `えーと、あの、ええと、その、まあ、えっと。ここのつ、10`(末尾の句点だけ外す)。言い淀みの列の終わりの句点は残し、届く文の句点の付け方を見せ続ける。
置換表・後処理・設定は増やさない。unit で「句点で終えない」「言い淀みの列の後の句点は残す」を守る。

## 結果

- yoji-01-r2・utt-31 が「一期一会の精神で…」。utt-25 は「1つ、…、9つ、10。」のまま
- corpus の 20 秒以下 210 本の新旧比較: 同じ 199、句読点・空白だけ違う 2、正解文に近づいた 3(yoji-01-r2、unit-01 の単位がかな書き、inhale-02 の「売上」)、
  離れた 6。離れた 6 本はペルソナの判定(数字・記号は Whisper の表記どおりで可、助詞の揺れは可)で ok のまま変わらないもの 5 本
  (count-01・jyoubun-01 の漢数字が数字に、eng-02 の「12万8000円」が「128000円」、sym-01 の「シャープ」が「#」、keigo-01 の「ところを」)と、
  記録済みの NG(far-01 遠い声。wontfix)の別の誤り 1 本(「実階」は「1階」に直ったが「受付」が「お客様」)
- 句点の無い末尾が数字なので、漢数字で書いていた数が数字に寄ることがある(表記の揺れ。読みも意味も同じ)
- 台本 `transcriber-3` の utt-31 は「一期一会」を含み「への」を含まないことを守る
