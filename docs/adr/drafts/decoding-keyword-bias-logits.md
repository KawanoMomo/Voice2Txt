# ADR-draft: カスタム語彙は whisper の復号の 1 手ごとに表記へ寄せ、寄せない復号と比べて採る

- **ステータス**: 提案(未採番)
- **カテゴリ**: architecture
- **日付**: 2026-11-04
- **対象プロジェクト**: Voice2Txt
- **関連**: decoding-initial-prompt-keywords.md、BLK-transcriber-20261104-1100(差し戻し 1 回目)

## コンテキスト

カスタム語彙(設定 `keywords`)の表記を初期プロンプトの前に足すと、名詞(「即達」→「速達」)は寄るが、動詞の活用形は寄らない:
`keywords=["寄って"]` でも「銭湯に寄って」は「銭湯に酔って」のまま。プロンプトの置き場所・句点・「銭湯に寄って」のような句・活用形を並べる・beam search の
どれでも変わらない(large-v3-turbo、コーパス sento-01-r2 と合成音声 utt-40)。プロンプトは文脈として読まれるだけで、復号の 1 手の選び方を直接は変えない。
Whisper.net 1.9.1 は whisper.cpp の logits filter callback(復号の 1 手ごとに次の語の点を書き換える入口)を公開していない。

## 検討した選択肢

1. 初期プロンプトの形を変える — 上のとおり、どの形でも「酔って」のまま(却下)
2. 語の置換表・後処理で書き換える — 1 語ずつ塞ぐことになり、音声を見ずに書き換える(owner の統合で却下)
3. 復号の 1 手ごとに、語彙の表記の続きになる語の点に定数を足す(浅い融合の文脈バイアス)だけ — 点 3 で「寄って」は寄るが、コーパス 397 本・語彙 7 語で
   語彙と無関係な所が 22 本変わった(「定例会議」→「定例議」、「川」→「河」、「甲と乙」→「河野と河野」、読点が落ちる等)
4. **3 に、足す所の制限と、寄せない復号との比較を加える**(採る)

## 決定

4 を採る(`KeywordBias`、`WhisperTranscriber.KeywordHook`)。

- 点(`KeywordBias.Bonus` = 3)を足すのは、モデルが次に文字を書こうとしているとき(最良の語がかな・漢字・英数で始まる)だけ。句読点・時刻・終わりの位置は動かさない
- 足す語は、書きかけの語彙の続き(無ければ語彙の頭)で、文字の切れ目で終わるもの。漢字の頭のバイトだけの語には足さない(同じ頭の別の漢字まで寄る)
- 寄せて 1 手でも選ぶ語が変わったら、同じ音声を寄せずに復号し直し、(a) 変わった所がすべて寄せた文字列の中の語彙の表記の丸ごとの出現に入り、
  (b) 寄せた分を除いた文の確からしさ(寄せた復号の対数確率 − 寄せない復号の対数確率 + 寄せた手の差)が −0.5 以上のときだけ寄せた方を採る。
  温度を上げたやり直しなどで 1 本の列として点を数えられなかった復号は採らない
- 変わらなければ復号は 1 回のまま。語彙が空なら callback を掛けない(今までと同じ)
- callback は、処理器が復号ごとに whisper.cpp へ渡す非公開のフィールド `whisperParams` に反射で書き込む。書けない・語の一覧を読めないときは寄せない
  (ログ `keyword-bias hooked=False`。初期プロンプトの語彙だけが効く)。語の一覧は読み込まれた whisper.dll の `whisper_token_to_str` で最初の復号時に読む

## 結果

- コーパス 397 本・語彙 7 語(寄って・速達・議事録・見積もり・打ち合わせ・河野・納品)で、寄せて語が変わったのは 11 本。採るのは「銭湯に寄って」の 2 本だけで、
  語彙の頭の 1 文字だけが入った置き換え(河・議・沖・寒・速)と「河野と河野」「寄ってきて、寄ってきては」は (a)(b) で落ちる
- 寄せて語が変わった発話は復号が 2 回になる(GPU で 1 回 0.25 秒前後。台本 transcriber-3 の utt-40 で離してから届くまで約 0.6 秒)
- Whisper.net を上げるときは、`whisperParams` と `LogitsFilterCallback` / `LogitsFilterCallbackData` の形、whisper_token_data の大きさ(56 バイト)を確かめる。
  形が変わっても落ちずに寄せないだけになる
- 台本 transcriber-3 は語彙に「寄って」を足し、最後に utt-40(銭湯に寄って)を流す
