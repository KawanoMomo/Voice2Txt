# ADR-draft: カスタム語彙は、文の読み(Windows の日本語 IME)で同音の書き分けと確かめられるときだけ強く寄せる

- **ステータス**: 提案(未採番)
- **カテゴリ**: architecture
- **日付**: 2026-11-05
- **対象プロジェクト**: Voice2Txt
- **関連**: decoding-keyword-bias-logits.md、decoding-initial-prompt-keywords.md、BLK-transcriber-20261104-1100(curator の書き直し後)

## コンテキスト

カスタム語彙の寄せ(`KeywordBias`、点 3)では、語彙「車」「車で」でも「週末に車で紅葉の名所へ」(kouyou-01 / -r2、合成音声 utt-41)は「週末に来るまで」のまま。
既定の Whisper(large-v3-turbo)はその手で「来」を「車」より 6.5〜7.0 だけ上に置く(「寄って」は 2.25 で寄った)。点 3 では足りず、
点を 8 に上げて全ての手に足すと、語彙の頭が文のあちこちで選ばれて復号が崩れ、温度を上げたやり直しになって 1 本の列として数えられない(採れない)。
点の大きさだけを守りにすると、音の違う語にも寄る(語彙「河野」で「甲と乙」が「河野と河野」)。同音か音の違う語かは、点(モデルの確からしさ)では分けられない。

## 検討した選択肢

1. 点を上げるだけ — 上のとおり文が崩れる。採る条件(語彙の中だけの変化・残りの確からしさ)は音の違う語への置き換えを落とせない(却下)
2. 語ごとの置換表・内蔵の読みの辞書 — 1 語ずつ塞ぐことになる(owner の統合で却下)
3. 利用者に読み(`表記=よみ`)を書かせて Whisper でも使う — 「車」のように読みを書かない語に効かない。読みは Haas のための書式のまま
4. **文の読みを Windows の日本語 IME(MSIME.Japan、`IFELanguage.GetPhonetic`)で得て、読みが同じときだけ強く寄せる**(採る)

## 決定

4 を採る(`KeywordBias.SoundsAlike` / `Plausible` / `BeginForced`、`WhisperTranscriber.DecodeByReadingAsync`、`ImeReading`)。

- 語彙があり IME が開けるとき(ログ `keyword-bias ... reading=ime`): まず寄せずに復号し、語彙の頭が最良の語から 8(`ReadingBonus`)未満の差にあった手を集める
- 集めた手のうち、語彙の読みがその手から後ろの読みの頭と合うもの(`Plausible`)だけを、差の小さい順に 1 つずつ試す: その手でだけ語彙の頭を選ばせ、その後は書きかけの語彙の続きにだけ 8 を足して書き切らせる(ほかの手には足さない)
- 採る条件は前の 2 つ(変わった所が語彙の丸ごとの中・寄せた分を除いた確からしさが −0.5 以上)に、寄せた文と寄せない文の読みが同じ(`SoundsAlike`)を足す。
  読みはひらがなに揃え句読点・空白を除き、同じ頭と終わりを除いた間の編集距離が長い方の 4 文字に 1 つ(少なくとも 1)まで(辞書に無い表記は IME が読みを外す: 「即達」→「そくたっ」)
- 採れたら、その後ろの手から同じように続ける。復号し直すのは 1 発話で高々 3 回
- IME が開けない(日本語 IME が無い等)ときは前の寄せ方(点 3 を全ての手に足して比べる)のまま(`reading=none`)。語彙が空なら IME も開かない
- IFELanguage は STA でしか使えない(MTA から作ると E_NOINTERFACE)ので、専用の STA スレッドで開いて使い続ける。読みは OS の中だけで求め、文は外へ出ない。IME は同梱しない

## 結果

- transcriber のコーパス 451 本・語彙 8 語(寄って・速達・議事録・見積もり・打ち合わせ・河野・納品・車)で、復号し直したのは 12 本・15 回、採ったのは 5 本
  (kouyou-01 / -r2「車で」、sento-01 / -r2・toshokan-01「寄って」)で、5 本とも正解文の表記。採った 5 本は語彙の無い復号と比べて語彙の所だけが変わった
- 1 発話の処理時間は平均 506 ms → 617 ms(中央値 433 → 445 ms)。寄せた発話は離してから届くまで約 0.6〜0.7 秒(台本 transcriber-3 の utt-40 / utt-41)
- 温度を上げたやり直しでは whisper.cpp が複数の列の手を別々のスレッドから呼ぶので、logits filter の中を 1 手ずつ(lock)にした(lock 無しでは検証モードで callback-failed ArgumentException が出て寄せが止まった)
- 範囲外: 音の違う語に当てる誤り(「近道」→「地下道」: 読みが違う)は、語彙に書いても採らない
