# ADR-draft: 小さい声が「取り消し(無音)」で消える — 無音の取り消しを録音の雑音に対して判定する

- **ステータス**: 提案(未採番)
- **カテゴリ**: architecture
- **日付**: 2026-10-07
- **対象プロジェクト**: Voice2Txt
- **関連**: 仕様 4.4・5 章(無音の取り消し)、BLK-human-20261007-2229-1、ADR-draft voice-level-relative-to-recording(詰め方の判定。そこでは取り消しの判定を変えなかった)

## コンテキスト

v0.4 の実機で「途中経過が出る前にトークキーを離すと入力されない」。実機のログ(`%APPDATA%\Voice2Txt\logs\app.log`)では、その間の
14 発話のうち 5 本が `reason=Silence`(押していた時間 1.1〜19.2 秒)で取り消されていた。取り消しの判定は「録音の最も大きい 30 ms 区間の RMS が
`SilenceThreshold`(初期値 0.01)未満」で、途中経過を作るかどうかも同じ判定だった。そのため「途中経過が出た」⇔「確定版が取り消されない」になり、
声が小さい(マイクの感度が低い)発話は途中経過が出ないまま、離すと黙って消えていた。途中経過の処理そのもの(並行の作り直し・離したときの中断)は
検証モードで離す時刻を 25 ms 刻みに変えても脱落 0 で、原因ではない。

## 検討した選択肢

1. しきい値の初期値を下げる — マイクごとに雑音の大きさが違い、固定の値では雑音だけの録音を復号に渡して音声に無い文を足す
2. 取り消しをやめる — 無音だけの押下で Whisper が音声に無い文(「ご視聴ありがとうございました」等)を作る問題が戻る
3. 録音の雑音に対して判定する: しきい値以上の区間があれば今までどおり声。無くても、雑音(静かな方から 5% の区間)の 4 倍以上かつ
   しきい値の 0.2 倍(0.002)以上の区間が合わせて 0.15 秒以上あれば声とみなす(ずっと同じ大きさの雑音・打鍵のような短い音は声にしない)

## 決定

3 を採る(`Audio.HasVoice`)。確定版の取り消し・途中経過・無音の詰め方(`TrimSilence` の「声が無ければそのまま」)が同じ判定を使う。設定項目は増やさない。
発話ごとのログに録音の大きさ `peakRms` を書く(本文は書かない)。次に取り消しが出たとき、声が小さかったのかをログで確かめられる。

## 結果

- 検証モード: しきい値の半分以下の小さい声(雑音 RMS 0.0003)の短い発話 2 本を、途中経過が出る前に離しても届く(`primary-7`。main では 2 本とも取り消し(無音))
- corpus 8 本を -30 dB と -40 dB に下げて雑音を重ねた音声: どれも取り消されず届く(-40 dB の 8 本は main では全部取り消し。届いた文に語の誤りが 2 本ある)
- 雑音だけ(RMS 0.0003・0.001)の 3〜4 秒と、雑音に打鍵のような短い音を足した録音は、今までどおり取り消し(無音)になる
- 残る危険: 声でない音(息・咳・物音)が 0.15 秒以上、雑音よりはっきり大きく続くと復号に渡る。届くのは Whisper の結果で、言い淀みと同じく空なら取り消しになる
